# Putra Jaya Pratama | Glass Website

Website company profile PJP berbasis React + TypeScript + Vite. Repository ini khusus untuk **konsep Atmospheric Glass** dan terpisah dari desain Pumpkin Industrial.

## Menjalankan proyek
\`\`\`powershell
npm ci
npm run dev
\`\`\`

## Build dan preview produksi
\`\`\`powershell
npm run build
npm run preview
\`\`\`

Build produksi **tidak menyertakan foto pekerjaan yang izin publikasinya belum terverifikasi**. Pada build publik, semua foto diganti ilustrasi SVG demo. Jangan hapus aturan privasi di \`vite.config.ts\` atau memasukkan foto asli ke repository sebelum ada konfirmasi izin.

## Deployment Cloudflare Pages
- Repository: private
- Production branch: \`main\`
- Build command: \`npm run build\`
- Output directory: \`dist\`
- Root directory: \`/\`
- Publikasi preview: ilustrasi demo, bukan foto proyek resmi

## Kolaborasi
- Fitur baru dikerjakan di branch masing-masing.
- Gunakan Pull Request untuk review sebelum merge ke \`main\`.
- Foto lokal (\`public/assets/pjp-preview\`) dan screenshot (\`preview/\`) tidak diunggah ke GitHub.
- Tambahkan detail proyek, kontak WhatsApp, dan informasi legal hanya setelah diverifikasi.

Baca juga \`docs/GLASS-DESIGN-README.md\`.
